import { Tabs, TabItem } from '@astrojs/starlight/components';

The SDKs are scaffolds. Each one holds configuration (the endpoint, an API
key, and an organization) and nothing that calls the platform yet; each grows
a client once its contract exists. None is published to a package registry
yet, so each installs from the
[`telmoni/telmoni-cli`](https://github.com/telmoni/telmoni-cli) repository.

| Language | Package / Module | Source |
|---|---|---|
| **TypeScript / JavaScript** | `telmoni` | [`sdk/typescript`](https://github.com/telmoni/telmoni-cli/tree/main/sdk/typescript) |
| **Python** | `telmoni` (Python 3.9 or later) | [`sdk/python`](https://github.com/telmoni/telmoni-cli/tree/main/sdk/python) |
| **Go** | `github.com/telmoni/telmoni-cli/sdk/go` | [`sdk/go`](https://github.com/telmoni/telmoni-cli/tree/main/sdk/go) |
| **Rust** | `telmoni-sdk` | [`sdk/rust`](https://github.com/telmoni/telmoni-cli/tree/main/sdk/rust) |

## Configuration

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { Telmoni } from 'telmoni';

    const fromEnv = Telmoni.fromEnv();

    const custom = new Telmoni({
      endpoint: 'https://telmoni.com',
      apiKey: process.env.TELMONI_API_KEY,
      organizationId: 'org_01j7abcde987654321',
    });
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    from telmoni import Config, Telmoni

    from_env = Telmoni.from_env()

    custom = Telmoni(
        Config(
            endpoint="https://telmoni.com",
            auth_token="telmoni_...",
            organization_id="org_01j7abcde987654321",
        )
    )
    ```
  </TabItem>
  <TabItem label="Go">
    ```go
    package main

    import (
    	telmoni "github.com/telmoni/telmoni-cli/sdk/go"
    )

    func main() {
    	fromEnv := telmoni.NewFromEnv()

    	custom := telmoni.New(telmoni.Config{
    		Endpoint:       "https://telmoni.com",
    		AuthToken:      "telmoni_...",
    		OrganizationID: "org_01j7abcde987654321",
    	})

    	_, _ = fromEnv, custom
    }
    ```
  </TabItem>
  <TabItem label="Rust">
    ```rust
    use telmoni_sdk::{Config, Telmoni};

    fn main() {
        let from_env = Telmoni::from_env();

        let custom = Telmoni::new(Config::new(
            "https://telmoni.com",
            Some("org_01j7abcde987654321".to_string()),
            Some("telmoni_...".to_string()),
        ));

        let _ = (from_env, custom);
    }
    ```
  </TabItem>
</Tabs>

## Environment variables

`fromEnv` / `from_env` / `NewFromEnv` read:

| Variable | Description | Default |
|---|---|---|
| `TELMONI_ENDPOINT` | The Telmoni platform endpoint | `https://telmoni.com` |
| `TELMONI_API_KEY` | An API key, created in project settings | None |
| `TELMONI_ORGANIZATION` | The active organization ID or slug (alias: `TELMONI_ORG`) | None |
