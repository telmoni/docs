Telmoni provides resilient monitoring infrastructure for scheduled background jobs,
pipelines, and autonomous AI agents. These documentation pages describe the open
core platform, console interface, developer tools, and HTTP API as implemented today.

## Platform capabilities

Telmoni open core provides the foundational workspace and operational substrate:

- **[Self-hosted deployment](/self-host/overview/)**: Run the complete platform
  on your own infrastructure using [Docker Compose](/self-host/docker-compose/) or
  Kubernetes, backed by PostgreSQL 17 with `pgvector` and Redis 7.
- **[Organizations and projects](/workspace/organizations-and-projects/)**: A
  clean two-tier tenancy model. Top-level organizations encapsulate projects,
  organization-level settings, and rolled-up audit events. Projects isolate API
  keys, notification connectors, and execution environments.
- **[Members and roles](/workspace/roles/)**: Role-based access control with
  three clear roles—**Owner**, **Admin**, and **Member**—governing both
  organization administration and project resources.
- **[Audit log](/workspace/audit-log/)**: Tamper-evident audit logging linking
  every state mutation into a cryptographic SHA-256 hash chain, verified nightly
  by background sweeps.
- **[Notifications and connectors](/integrations/notifications/)**: Real-time
  feed updates and fan-out dispatch to [Slack, Discord](/integrations/slack-and-discord/),
  and signed [Webhooks](/integrations/webhooks/).
- **[Telmoni CLI](/api/cli/)**: The official command-line interface with interactive
  device code authorization ([RFC 8628](https://www.rfc-editor.org/rfc/rfc8628)),
  organization switching, and scriptable JSON output.
- **[Client SDKs](/api/sdks/)**: Official client libraries for TypeScript / JavaScript,
  Python, Go, and Rust.
- **[API keys and /v1 API](/api/api-keys/)**: Scoped `telmoni_` project tokens
  with zero-downtime 24-hour rotation grace periods, authenticating the
  read-only [API](/api/reference/).
